# PorousFlowWaterVapor

!syntax description /UserObjects/PorousFlowWaterVapor

## Phase numbering

The phase numbering is fixed by this class: the liquid phase is phase 0 and the gas phase is
phase 1. The `liquid_phase_number` parameter is deprecated - this is no longer a user option, and
any value other than 0 is an error.
