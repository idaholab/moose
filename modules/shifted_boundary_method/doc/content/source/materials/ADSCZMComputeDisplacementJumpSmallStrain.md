# ADSCZMComputeDisplacementJumpSmallStrain

!syntax description /Materials/ADSCZMComputeDisplacementJumpSmallStrain

The `ADSCZMComputeDisplacementJumpSmallStrain` material is the automatic-differentiation version of
[`SCZMComputeDisplacementJumpSmallStrain`](SCZMComputeDisplacementJumpSmallStrain.md). It computes
the shifted displacement jump at the true interface and rotates it into the local interface
coordinate system. This object is normally created by the
[ShiftedCohesiveZone action](ShiftedCohesiveZoneAction.md).
