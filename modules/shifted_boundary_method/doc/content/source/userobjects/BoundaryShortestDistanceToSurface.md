# BoundaryShortestDistanceToSurface

!syntax description /UserObjects/BoundaryShortestDistanceToSurface

`BoundaryShortestDistanceToSurface` stores the distance and true-interface normal used to shift
quantities from selected surrogate boundaries. Distances may come from one function per boundary or
from an [`SBMInterfaceManager`](SBMInterfaceManager.md) and explicit subdomain pairs. The shifted
cohesive zone action can create and configure this object automatically.
