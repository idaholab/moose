# ADSCZMInterfaceKernelSmallStrain

!syntax description /InterfaceKernels/ADSCZMInterfaceKernelSmallStrain

The `ADSCZMInterfaceKernelSmallStrain` is the automatic-differentiation version of
[`SCZMInterfaceKernelSmallStrain`](SCZMInterfaceKernelSmallStrain.md). It assembles cohesive
traction on a surrogate interface and obtains Jacobian contributions through automatic
differentiation. This object is normally created by the
[ShiftedCohesiveZone action](ShiftedCohesiveZoneAction.md).
