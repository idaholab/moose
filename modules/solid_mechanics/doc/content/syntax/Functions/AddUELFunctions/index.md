# AddUELFunctions Action

The `Functions/AddUELFunctions` action adds one function for each `*Amplitude` table in the
[AbaqusUELMesh](mesh/AbaqusUELMesh.md). Use it inside the `[Functions]` block to avoid declaring the
amplitude functions manually.

!syntax list /Functions/AddUELFunctions objects=False actions=True subsystems=False
