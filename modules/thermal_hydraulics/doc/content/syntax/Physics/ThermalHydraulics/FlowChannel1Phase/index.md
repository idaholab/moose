# FlowChannel1Phase Physics syntax

The `[FlowChannel1Phase]` block is a sub-block of the `[ThermalHydraulics]` block of the
[Physics](syntax/Physics/index.md) system. It holds the [FlowChannel1PhasePhysics.md] objects, which
define the single-phase flow equations of a [FlowChannel1PhaseAC.md].
