## MOOSE Improvements

- `LinearNodalConstraint`, `EqualValueBoundaryConstraint` and `EqualValueEmbeddedConstraint` have
  a new option, `formulation = exact`. With this option, the constraint gives libMesh one
  degree-of-freedom constraint row per secondary node. libMesh removes the tied degrees of freedom
  from the system before the solve, so the tie is exact and needs no `penalty`. This also gives
  the correct mass matrix in an eigenvalue solve. A Control can change the `weights` of a
  `LinearNodalConstraint` during the run.
- The new `MultiPointConstraint` base class ties degrees of freedom with exact constraints in the
  libMesh `DofMap` instead of a residual
  ([idaholab/moose#33821](https://github.com/idaholab/moose/issues/33821)).

## MOOSE Modules Changes

### Solid mechanics module

- `RBE2Constraint` ties a set of dependent nodes rigidly to one independent node.
  `RBE3Constraint` moves a reference node as the weighted least-squares fit of a set of independent
  nodes, and adds no stiffness. Both use exact constraints
  ([idaholab/moose#33821](https://github.com/idaholab/moose/issues/33821)).
