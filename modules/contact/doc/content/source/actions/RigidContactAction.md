# RigidContactAction

!syntax description /RigidContact/RigidContactAction

## Description

`RigidContactAction` expands a single `[RigidContact][<name>]` sub-block
into every object the analytic-level-set rigid-body contact stack needs.
Users almost always interact with it through the
[`[RigidContact]` block](syntax/RigidContact/index.md) rather than the
class directly; see that page for a description, worked examples, and the
list of expanded objects.  For the theoretical background see the
[rigid-body contact theory](modules/contact/rigid_contact/theory.md) page.
