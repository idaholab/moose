# ScalarReaction / ADScalarReaction

!syntax description /ScalarKernels/ScalarReaction

## Description

`ScalarReaction` (and its automatic differentiation version, `ADScalarReaction`) implements a
consuming reaction term for a scalar variable $u$:

\begin{equation}
\lambda u
\end{equation}

where $\lambda$ is the [!param](/ScalarKernels/ScalarReaction/rate).
