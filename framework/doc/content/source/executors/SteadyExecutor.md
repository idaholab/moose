# SteadyExecutor

!syntax description /Executors/SteadyExecutor

## Overview

`SteadyExecutor` runs the problem initial setup, then runs each executor in
[!param](/Executors/SteadyExecutor/inner_executors) in order, and then performs the final
execution and output.
