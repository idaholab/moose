# SubdomainPerElementGenerator

!syntax description /Mesh/SubdomainPerElementGenerator

The user may create one subdomain for each element by not providing the [!param](/Mesh/SubdomainPerElementGenerator/subdomain_ids) parameter. This is a convenient way to create very many
subdomains for scalability studies in the number of subdomains.

!syntax parameters /Mesh/SubdomainPerElementGenerator

!syntax inputs /Mesh/SubdomainPerElementGenerator

!syntax children /Mesh/SubdomainPerElementGenerator
