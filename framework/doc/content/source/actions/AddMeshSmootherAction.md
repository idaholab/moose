# AddMeshSmootherAction

!syntax description /Remeshing/Smoothers/AddMeshSmootherAction

The AddMeshSmootherAction is a [MooseObjectAction.md] that creates the specified MeshSmootherBase
object for each block of the `[Remeshing/Smoothers]` block of an input file, then adds it to the
[Problem](syntax/Problem/index.md). See [syntax/Remeshing/index.md] for more information.

!syntax parameters /Remeshing/Smoothers/AddMeshSmootherAction
