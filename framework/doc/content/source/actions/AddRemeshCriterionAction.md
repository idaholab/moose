# AddRemeshCriterionAction

!syntax description /Remeshing/Criteria/AddRemeshCriterionAction

The AddRemeshCriterionAction is a [MooseObjectAction.md] that creates the specified RemeshCriterion
object for each block of the `[Remeshing/Criteria]` block of an input file, then adds it to the
[Problem](syntax/Problem/index.md). See [syntax/Remeshing/index.md] for more information.

!syntax parameters /Remeshing/Criteria/AddRemeshCriterionAction
