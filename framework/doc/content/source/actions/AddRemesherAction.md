# AddRemesherAction

!syntax description /Remeshing/Remeshers/AddRemesherAction

The AddRemesherAction is a [MooseObjectAction.md] that creates the specified Remesher object for
each block of the `[Remeshing/Remeshers]` block of an input file, then adds it to the
[Problem](syntax/Problem/index.md). See [syntax/Remeshing/index.md] for more information.

!syntax parameters /Remeshing/Remeshers/AddRemesherAction
