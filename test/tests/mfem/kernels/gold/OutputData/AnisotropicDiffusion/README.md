# Anisotropic Diffusion Gold

You can regenerate data similar to that in `Run0/` using
MFEM revision b7ac1963bbb85fa0d5db61fbcb19f47389b79f8b, after
applying the below patch to the `examples/ex29p.cpp` file.
The patch updates the example to use constant values in its coefficient matrix,
and write the output mesh in PVD ASCII format.
Run the example with no extra arguments.

These gold files are not directly generated by MFEM,
because there seems to be differences in "piece" numbering.
The gold data here was generated by MOOSE.
You can compare the MFEM and MOOSE generated meshes
in something like ParaView and see that they are equal
to an absolute tolerance of around 1e-12.
